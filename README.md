# Brote

Agenda progresiva para organizar los cuidados diarios de plantas. Las tareas se guardan en el dispositivo y la app puede instalarse y abrirse sin conexión después de la primera visita.

## Ejecutar

Sirve los archivos desde `localhost` o HTTPS para habilitar el service worker:

```sh
python3 -m http.server 8000
```

Abre `http://localhost:8000` en el navegador.
